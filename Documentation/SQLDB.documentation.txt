    `ID` int(11) NOT NULL AUTO_INCREMENT,
        NB! - for existing databases that have a ID as primary key can use: "fields" : ["whateverkey as ID", other fields]
    it is recommend that all tablenames begin with "tbl" i.e. "tblNames"
    fieldnames must match fieldnames in JSON form files. (form.documentation.txt)
